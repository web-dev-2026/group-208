# Vazifalar

Har bir vazifa shu papkada alohida fayl: `01-html-basics.md`, `02-tables.md`, ...

Vazifa uchun papkangizda **xuddi shu nomli** papka yarating:
`tasks/02-tables.md` → `students/ism-familiya/02-tables/`

Yangi vazifa qo'shilganda uni olish uchun sinxronlang:

```bash
git checkout main
git pull upstream main
```
